# How to Install FocusLens in Microsoft Edge

To enable strict Reels & Shorts blocking directly inside your standard Microsoft Edge browser:

1. Open **Microsoft Edge**.
2. In the URL bar, type:
   ```
   edge://extensions
   ```
3. In the bottom-left sidebar, switch on the toggle for **Developer mode**.
4. Click the button at the top that says **"Load unpacked"**.
5. Select this directory:
   ```
   C:\Users\joshm\.gemini\antigravity\scratch\focus-lens\edge_extension
   ```
6. FocusLens will now automatically intercept YouTube Shorts (converting them to standard video players) and strictly block all Instagram Reels directly inside Microsoft Edge!
