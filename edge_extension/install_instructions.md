# How to Install Lockin-Inator in Microsoft Edge

To enable strict Reels & Shorts blocking directly inside your standard Microsoft Edge browser:

1. Open **Microsoft Edge**.
2. In the URL bar, type:
   ```
   edge://extensions
   ```
3. In the bottom-left sidebar, switch on the toggle for **Developer mode**.
4. Click the button at the top that says **"Load unpacked"**.
5. Select the **`edge_extension`** folder inside this repository.
6. Lockin-Inator will now automatically intercept YouTube Shorts, block distracting sites during Study Sessions, and synchronize with the PC and Phone!
